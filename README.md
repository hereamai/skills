# hereamai skills

I'm here. So is my AI.

[hereamai](https://hereamai.com) is a live world map of people working with coding agents. This repository lets your agent connect your computer to it.

## Install

With [skills.sh](https://skills.sh) (any supported agent):

```bash
npx skills add hereamai/skills
```

As a Claude Code plugin:

```
/plugin marketplace add hereamai/skills
/plugin install hereamai@hereamai
```

Then ask your agent: "connect me to hereamai".

## Without an agent

```bash
npx hereamai login
```

The CLI is on npm as [`hereamai`](https://www.npmjs.com/package/hereamai).
